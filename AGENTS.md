If using AI agents to maintain this repo, always use anonymized survey data (e.g. replace uniqnames with random numbers) to ensure student privacy.

To avoid any potential conflicts with FERPA, it is best practice to ensure AI agents never see *any* student data while testing.

Never commit any student data or test data (student_data or test_data folders). Never commit outputs (study_group_emails.txt).

Never commit matcher outputs that may contain student identifiers (e.g. study_group_emails.txt, groups.txt).
